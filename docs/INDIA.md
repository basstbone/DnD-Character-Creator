            **So that** more time is spent playing than creating

## WHY
Problem/Opportunity --- The current best DCCs have most selections locked behind a paywall and the free ones just dump info on you without an explanation.<br>
Value proposition --- For DnD players, my application will help explain what everything on a character sheet is for because right now there is a steep learning curve for new players.

## What already exists
### What is good?
The websites offer useful features like step-by-step character creation, automatic stat calculations, character customization, random character generation, and the ability to save or print character sheets.
### What is bad/missing?
Some websites are too complicated for beginners, while others have outdated or cluttered designs. Some features require payment, and certain websites do not explain character creation very well.
### What functionality matters?
The most important features are choosing a species, class, and background, automatically calculating stats, saving and editing characters, generating random characters, and printing character sheets.
### What can we borrow/avoid?
I can borrow the step-by-step creation process, automatic calculations, customization options, and random character generation. I should avoid complicated menus, cluttered pages, and unnecessary restrictions.
### Why build another one?
I want to create a simple, beginner-friendly D&D character creator that combines the best features of existing websites. My goal is to make character creation quick, easy to understand, and customizable without overwhelming users.
