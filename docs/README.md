Team --- Sean Oliver/solo<br>
User Story --- **As a** Dnd Player
            **I want** to be able to quickly make characters
            **So that** more time is spent playing than creating

### WHY
Problem/Opportunity --- The current best DCCs have most selections locked behind a paywall and the free ones just dump info on you without an explanation.<br>
Value proposition --- For DnD players, my application will help explain what everything on a character sheet is for because right now there is a steep learning curve for new players.
